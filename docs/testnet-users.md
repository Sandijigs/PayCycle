## Recruitment Sources

### Circle 1: SCF Project Teams (Target: 2-3)
- Teams you've been engaging with on Discord and X
- Approach: DM with plan link + 2-minute ask
- Example message:
  > "Hey! I built a recurring payments protocol on Soroban — would you test it on testnet? Takes 2 min: [plan link]. Just subscribe with Freighter on testnet. Would love your feedback!"

### Circle 2: Stellar Discord #builders (Target: 3-5)
- Post in #builders channel with clear CTA
- Example post:
  > "Built PayCycle — recurring payments on Soroban. Looking for 5 testnet users to try the subscribe flow. Takes 2 min, just need Freighter on testnet. Plan link: [link]. Feedback form built in. Thanks!"

### Circle 3: Journey to Mastery Peers (Target: 1-2)
- Cross-test with other builders in the program
- Offer to test their project in return
